# 网络设备出入库管理系统（网页版）

面向机顶盒、ONU、交换机、分光器等网络设备的 **入库 / 出库登记**、**实时库存**、**单据追溯**、**报表** 与 **角色权限**；支持 **扫码登录**（电脑端展示二维码，手机扫码后在手机上确认授权）。

## 技术栈

- Next.js 14（App Router）+ TypeScript + Tailwind CSS
- Prisma + PostgreSQL（关系型数据库；角色与单据类型在库里用字符串存储，类型在 `src/lib/db-enums.ts` 中约束）
- 密码哈希（bcrypt）+ JWT 会话 Cookie
- 扫码登录：服务端生成二维码（`qrcode`），手机打开确认页完成账号密码校验

## 环境要求

- Node.js **18+**（建议 LTS）
- npm 或 pnpm / yarn

## 快速开始

```bash
cd network-equipment-wms
copy .env.example .env
npm install
npx prisma db push
npm run db:seed
npm run dev
```

浏览器访问：`http://localhost:3000`

### 升级 / 重置数据库（结构变更后）

若从旧版本升级或 `db push` 报错，可在 PostgreSQL 中重置数据库（例如清空 `public` 模式下的表）后重新执行：

```bash
npx prisma db push
npm run db:seed
```

### 环境变量说明（`.env`）

| 变量                    | 说明                                                                                      |
| --------------------- | --------------------------------------------------------------------------------------- |
| `DATABASE_URL`        | PostgreSQL 连接串（例如 `postgresql://postgres:Ljw123@localhost:5432/postgres?schema=public`） |
| `SESSION_SECRET`      | **至少 16 位**随机字符串，用于签发登录会话                                                               |
| `NEXT_PUBLIC_APP_URL` | 对外访问根地址，用于生成扫码登录链接。**局域网用手机扫码时，请改为电脑的 IP**，例如 `http://192.168.1.10:3000`                |

## 默认账号（种子数据）

| 用户名        | 密码            | 角色                        |
| ---------- | ------------- | ------------------------- |
| `admin`    | `admin123`    | 管理员（设备类型、用户管理）            |
| `operator` | `operator123` | 仓管员（可登记出入库）               |
| `user`     | user123       | 仓管员（可登记出入库，与 operator 同级） |

**生产环境请务必修改密码，并更换** **`SESSION_SECRET`。**

## 功能说明

- **设备结构**：一级为设备大类（机顶盒、ONU、分光器、交换机、收发器、模块），二级为**具体型号 SKU**。
- **设备类型（管理员）**：维护大类与型号；删除需满足无库存、无历史单据等约束。
- **入库 / 出库**：先选大类再选型号；自动生成单号（`RK`/`CK` + 日期 + 序号），出库校验库存。
- **库存 / 出入库记录**：按型号展示；记录含**登记时间**、**操作者账号与姓名**。
- **报表**：按大类、按型号汇总；**导出汇总 CSV**（含导出时间、筛选区间）；**导出明细 CSV**（逐条单据，含时间、操作者、型号等）。
- **权限**：管理员 / 仓管员 / 只读；管理员可**删除用户**（已有出入库登记操作记录的用户不可删，需先禁用）。
- **扫码登录**：登录页「扫码登录」→ 手机扫码 → 在手机上输入账号密码确认 → 电脑端自动登录；确认页已做移动端适配与安全区留白。

## 生产部署提示

- 使用 `npm run build` + `npm run start`，并配置反向代理与 HTTPS。
- 定期备份 PostgreSQL 数据库。
